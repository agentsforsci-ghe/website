Step 7: Set up Zotero

Due by Friday, 25 September 2026

One of the tasks on the day is a literature review, and the agent does it against your own reference library. This page sets up Zotero, the free and open source reference manager, the way we use it in the group. If you already use Zotero, skim to Step 5 and check the settings from there on. The citation key settings in Step 7 are the group convention and are worth checking even on a library you have used for years.

Written against Zotero 10 (10.0.3, September 2026), which came out in August, and the current Better BibTeX release. If you run an older Zotero, update it first. Two things differ from older guides you may find online: the Sync tab in the settings is now called Account, and Better BibTeX runs on Zotero 10 even though its release notes still name older versions.

ImportantWhat to have in the library by the workshop

Five to ten references related to the data you brought are enough, with PDFs attached where you have them. If you have none in Zotero yet, use Semantic Scholar or Connected Papers to find them quickly and save them with the connector from Step 3. It does not matter whether they are the best references for the work. The point is having a library to work with, and the search is good experimentation on its own. Everything can be reverted or started from scratch after what you learned.

What you are setting up

  • Zotero, the desktop app. It stores your references, the PDFs attached to them, and your reading highlights.
  • A zotero.org account with sync, so your library is backed up and available on other devices.
  • The Zotero Connector, a browser extension that saves papers into your library with one click.
  • Better BibTeX, a Zotero plugin that gives every item a stable short ID called a citation key, for example forte2022building. Citation keys are how Quarto, LaTeX and other plain text tools refer to items.
  • Two settings inside Zotero: local access for other apps on your computer, which step 8 depends on, and Quick Copy, which puts a citation key on your clipboard with one keystroke.

Step 1: Install Zotero

  1. Go to zotero.org/download.
  2. Download the installer for your platform and install it like any other app.
  3. Open Zotero once so it can create its data folder.

If Zotero is already installed, update it before you continue. On macOS use Zotero, Check for Updates. On Windows use Help, Check for Updates. The steps below were checked on Zotero 10 and need Zotero 7 or newer.

Throughout this page, “Settings” means the window you open with Zotero, Settings on macOS or Edit, Settings on Windows.

Step 2: Create an account and turn on sync

  1. Create a free account at zotero.org/user/register and confirm the email it sends you.
  2. In Zotero, open Settings, Account (older versions call this tab Sync).
  3. Sign in with your new account.
  4. Leave the data syncing defaults as they are. Data syncing covers your references, notes, tags and highlights. It is free and has no size limit.

File syncing is a separate switch on the same tab and covers the PDFs themselves. Every account gets 300 MB of file storage for free. Keep it on with the “Zotero” option if you want to read your PDFs on a second device; decide about paid storage later if the library outgrows the free tier.

Step 3: Install the browser connector

  1. In the browser you normally use, go to zotero.org/download. The page detects your browser and offers the matching connector.
  2. Install the extension and pin its button to the toolbar.
  3. Keep the Zotero desktop app open while you save. The connector hands items to the desktop app.

To save an item, open the paper’s page (the journal landing page, an arXiv abstract page) and click the connector button. Zotero saves the reference and, when it has access, the PDF.

Two other ways to add items, both inside Zotero: click the magic wand button and paste a DOI, ISBN, PMID or arXiv ID, or drag a PDF file into the Zotero window and check the metadata it reads out of it.

Step 4: Know your way around the library

If you have used a reference manager before, skim this. If Zotero is your first one, ten minutes here pay off.

  • The left pane lists your collections. A collection is a folder you assign items to. One item can sit in several collections at once.
  • The middle pane lists the items in the selected collection. An item is the reference record: title, authors, year, journal, DOI.
  • Attachments (the PDF), notes and tags hang off an item. Click the arrow next to an item to see them.
  • The right pane shows the selected item’s fields. Fix obvious metadata errors as you notice them, because everything downstream builds on these fields.
  • Double-click an item to open its PDF in Zotero’s reader. Highlights are stored in Zotero’s database and sync like any other data.

Save two or three real papers now so you have something to test with.

Step 5: Allow other apps to talk to Zotero

Step 8 connects the agent to your library through a local connection on your own computer. One checkbox enables it.

  1. Open Settings, Advanced.
  2. Check Allow other applications on this computer to communicate with Zotero.

The connection only works for apps running on the same computer. Nothing is exposed to the internet.

Step 6: Install Better BibTeX

Better BibTeX is installed from a downloaded file.

  1. In your browser, go to the Better BibTeX releases page and download the latest .xpi file. You want the file saved to disk, not opened by the browser.

    • Safari
    • Firefox
    • Chrome and Edge

    Click the .xpi link. Safari downloads it to your Downloads folder. If it opens a viewer instead, right-click the link and choose Download Linked File.

    Firefox tries to install .xpi files as Firefox extensions, which is the wrong target. Right-click the link and choose Save Link As.

    Click the link. If the browser warns that the file may be dangerous because it is an uncommon type, choose Keep. The file is safe.

  2. In Zotero, go to Tools, Plugins.

  3. Click the gear icon, choose Install Plugin From File, and select the .xpi you downloaded.

  4. Restart Zotero when prompted.

After the restart, the Settings window has a new Better BibTeX tab.

Step 7: Configure the citation keys

This is the step to get exactly right.

A citation key is a short, readable ID for one item, like forte2022building. Once other tools refer to your items by these keys, a key must never change. When everyone in a group generates keys the same way, a paper shared through a group library carries the same key in every member’s library, and drafts move between people without anyone rekeying citations. The formula below is the shared convention at Global Health Engineering.

Open Settings, Better BibTeX. Under Citation keys:

  1. Set the citation key formula to:

    auth.lower + year + veryshorttitle(1, 0).lower

    Read left to right: the last name of the first author, lowercased; the publication year; the first meaningful word of the title, lowercased. Tiago Forte’s 2022 book “Building a Second Brain” gets the key forte2022building.

  2. Set Automatically fill citation key after to 2 seconds. Filling writes the generated key into the item’s own Citation Key field, where it is saved and synced.

  3. Check that Regenerate citation key when item changes is unchecked. With it unchecked, a filled key stays as it is even when you later fix a typo in the author or title, which is what you want. If it is checked, uncheck it now.

Leave the remaining defaults. Then add a Citation Key column to your item list: right-click the column header in the middle pane and tick Citation Key.

Items that were already in your library may carry keys from the old default formula. Select them, right-click, and choose Better BibTeX, Regenerate citation key. Do this now, before anything refers to the old keys.

Step 8: Set up Quick Copy

  1. Open Settings, Export.
  2. Under Quick Copy, set Item Format to Better BibTeX Citation Key Quick Copy.
  3. Check that Note Format is Markdown + Rich Text and that Include Zotero Links is ticked on the Markdown line.

From now on, selecting an item and pressing Cmd+Shift+C on macOS or Ctrl+Shift+C on Windows copies its citation key.

Check

Save one more paper with the connector. Within two seconds its right pane shows a Citation Key in the shape authorYEARword. Select it, press the Quick Copy shortcut, paste into any text editor, and you get the bare key. Edit the title, wait two seconds, and confirm the key did not change. If all three worked, the setup is complete, and step 8 connects it to the agent.
